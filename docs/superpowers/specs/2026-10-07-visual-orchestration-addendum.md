# 管理端可视化编排补充设计

用户要求增加并继续实现拖拽模块、多模型混合、知识库选择连接与参数调整，本补充并入已批准的知识工作台交付。

管理人员在画布添加、拖动、连接节点，侧栏调整参数。支持缩放、平移、撤销/重做、保存草稿、校验、发布、回滚、JSON 导入导出和试运行。

节点覆盖输入、知识库检索、元数据过滤、去重截断、重排、证据门控、提示模板、模型、多模型融合和输出。可并行连接不同知识库和模型，常用模板包括严格客服、多库检索、多模型融合。

检索参数包括多知识库、top-k、阈值、混合权重、重排、元数据过滤与上下文预算。模型参数包括提供者标签、兼容 endpoint、模型 ID、超时、温度、top-p、最大输出和系统提示。API Key 使用部署环境变量引用，读取和导出不含明文。endpoint 必须匹配部署者允许主机，私有/本机服务显式允许；不支持任意代码、命令或 HTTP 工具执行。

知识库保存切分、重叠与解析配置。embedding 变更不能直接污染旧索引；维度/模型变化要求新索引显式迁移。支持清单以实际适配器为准，不提供只保存但不生效的模型选项。

服务端验证类型端口、所有节点与边、循环、输出可达性、知识库/模型租户范围。上限 40 节点、80 边、6 次模型调用，时间与 token 受限。发布创建不可变版本，草稿不影响线上运行；回滚指向历史版本。运行记录显示每步真实状态、耗时和结果数量，默认不记录敏感原文。

严格模板在无证据时短路，不调用模型。并行模型可以指定主模型综合或并列展示，部分失败明确显示降级，模型多数票不等于事实保证。取消/超时终止剩余任务并释放未成功用量。

验收：画布建立输入、双知识库检索、去重、双模型、综合、输出并实际执行；参数变化到达 Fake 适配器；刷新恢复配置、发布隔离草稿、回滚和逐节点追踪可用；循环、非法端口、跨组织资源、秘密回显、未允许 endpoint 与预算超限被拒绝；浏览器验证拖拽连线、侧栏、撤销/重做、缩放、导入导出和试运行。文档逐项列出实际能力与边界，不宣称覆盖所有行业或所有模型。
