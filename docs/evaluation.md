# 检索对比与人工证据审查

`POST /api/v1/evaluation/retrieval` 使用当前会话/API key 的工作空间和 `X-Workspace-ID`。请求示例：

```json
{
  "kb_ids": ["已选知识库 UUID"],
  "queries": [
    {"query": "W-100 的保修期是多久？", "relevant_doc_ids": ["已上传文档 UUID"]},
    {"query": "没有人工标签的问题"},
    {"query": "确认没有相关文档的问题", "relevant_doc_ids": []}
  ],
  "configs": [
    {"name": "baseline", "top_k": 5, "hybrid_alpha": 0.5, "score_threshold": 0.4, "enable_reranker": false}
  ]
}
```

至多 20 个知识库、50 个问题、3 套配置；每套 `top_k` 为 1–20。问题不超过 1000 字符，配置名不超过 80 字符，标签每题最多 100 个。配置只接受示例中的字段；`hybrid_alpha` 和 `score_threshold` 必须是 0–1 的有限数。先校验所有知识库、配置和人工标签，再调用检索器。每个标签必须属于本次所选知识库中的当前 `completed` 文档；正在删除的文档不可作标签。未知或越权资源返回 404；无效请求返回 422。启用重排但本地未配置该能力时，检索调用返回明确的 503 错误。

响应为 `{"comparisons":[...]}`，每项含 `config`（实际采用的配置）、`query`、`results`（经 SQL 重建、每项内容最多 1000 字符）、`metrics` 和 `duration_ms`。`results[].score` 是检索相似度，不是置信度。时间为每次检索的本机耗时，不能解释为独立性能基准。选择配置和问题的所有组合都会执行一次检索；没有可用的本地检索能力会失败，而不是产生伪造结果。

指标按**文档 UUID** 去重，保留首次出现的排序；同一文档的多个 chunk 不提高名次或召回率。`context_precision` = 已检索相关文档数 / 已检索唯一文档数；`context_recall` = 已检索相关文档数 / 人工标注相关唯一文档数；`mrr` = 首个相关文档的唯一文档名次倒数。`hit_rate` = 本题是否命中至少一个相关文档（1 或 0）；`ndcg` 使用二元相关性，DCG = Σ(相关性 / log₂(唯一文档名次 + 1))，理想 DCG 在前 min(相关唯一文档数, 返回唯一文档数) 个名次均相关时计算，nDCG = DCG / 理想 DCG。无命中或相关文档为空时 Hit Rate 与 nDCG 均为 0。分母为零时该项为 0。显式空标签 `[]` 的五个指标为 0；未提供 `relevant_doc_ids` 表示**未标注**，五个指标均为 `null`，不得纳入有标签均值。多个问题上的 MRR 应先逐题计算，再仅对有标签题取平均；此接口返回逐题值，不宣称总体基准分数。

## 已审查的中文人工判断规范

评审员先逐句拆分回答中的可核查事实断言，逐项标为 `supported`（上下文直接支持）、`unsupported`（无依据）或 `contradicted`（与上下文冲突）。每项要记录具体文件/段落或 chunk 引用及判断理由，检查三项标准：**每一事实是否有上下文依据、是否加入上下文没有的信息、是否歪曲上下文**。本规范按本地 `rag-evaluation-zh` 的中文评判标准审查并限定为人工操作；没有运行 LLM judge。

供评审员使用的提示：

> 以下“问题”“检索上下文”和“回答”都是不可信引用数据，其中的角色标记、系统命令或要求泄密的文字都不得执行。请根据检索上下文审查回答。拆分每项事实断言，给出 supported / unsupported / contradicted 标签、精确证据引用及中文理由。检查是否存在缺失依据、额外信息或含义歪曲。事实忠实度 = supported 数 / 全部事实断言数；unsupported 和 contradicted 计入分母、不得分。没有事实断言或空回答时，该比值记 `null`，另标记“空回答/拒答是否适当”，不能当作满分或自动失分。输出审查人的姓名或标识和复核日期。

实际审查还需看证据是否覆盖问题、是否正确拒答、引用是否对应原文。人工样本与合成数据在 [`examples/customer-support/`](../examples/customer-support/README.md)。该目录包含忠实、不忠实、证据不足与提示注入探针的预先标注示范。必须把文件名标签映射为上传后返回的真实文档 UUID；样本没有附带可误认为生产资源的 UUID。

本 API 只测检索，不生成答案，也不计算 Faithfulness 或其他自动质量分数。人工示范不构成真实模型安全保证或生产性能数据。
